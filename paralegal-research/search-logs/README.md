# Search-log index

Search logs record how a systematic research pass was bounded. They preserve
queries, repositories, dates, exclusions, inaccessible materials, negative
results, and follow-up leads. A negative result means only that the documented
search did not locate a usable source; it is never proof that no authority
exists.
