# AUTH-0019: Server Side Public License 1.0

## Citation and source

- [Official MongoDB SSPL-1.0 text](https://www.mongodb.com/legal/licensing/server-side-public-license); [MongoDB licensing page](https://www.mongodb.com/legal/licensing/community-edition).

## Procedural posture and weight

Primary licensor text. It is source-available; it is not listed in the OSI approved registry.

## What it supports

- GPLv3-style conveyance/source terms apply, while s. 13 requires a provider making program functionality available to third parties as a service to offer Service Source Code to all network users without charge.
- Section 8 supplies GPLv3-style termination/reinstatement; s. 11 provides patent terms. No forum/law clause is selected.
- MongoDB states commercial licenses are available for its Community Server offerings.

## What it does not establish

- That every hosted application triggers s. 13, that SSPL is OSI-approved, or a court remedy.

## Key facts and reasoning

“Service Source Code” is defined in s. 13 and can reach management software used to provide the service; exact application needs technical facts.
