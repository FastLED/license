# AUTH-0141: Redis Source Available License 2.0

## Citation and source

- [Official Redis RSALv2 agreement](https://redis.io/legal/rsalv2-agreement/); [Redis licensing overview](https://redis.io/legal/licenses/).

## Procedural posture and weight

Primary licensor agreement. Redis calls RSALv2 source-available/non-copyleft; it is not in OSI's approved registry.

## What it supports

- It grants use/copy/distribution/availability/derivative rights but prohibits providing the software's functionality to third parties as a service or distributing it so its functionality is available to third parties.
- It requires license and modification notices, includes a patent grant with patent-claim termination, and provides a first 30-day notice-and-cease retroactive reinstatement; a later breach is permanent termination.
- It specifies jurisdiction-dependent California/Santa Clara, Israel/Central District, or England and Wales/London law and courts.

## What it does not establish

- Whether a given hosted offering provides the software's functionality, the result under an alternative Redis license, or a remedy.
